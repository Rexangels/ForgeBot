# ForgeBot

ForgeBot is a proposed autonomous cyber-physical robotics factory for the Meta Global AI Developer Hackathon “Push the Frontier” track. The goal is to help engineers turn a robotics mission brief into reviewable design artifacts, validated robot descriptions, optional simulation results, and an exportable prototype package.

## Project status

The GitHub repository currently contains the project title and concept only. The architecture below is a target design, not a claim that these components or workflows are implemented. The initial implementation should choose a single backend stack and support one constrained robot class end to end before expanding capabilities.

## Architecture

See [ARCHITECTURE.md](ARCHITECTURE.md) for the proposed component boundaries, workflow, validation and security requirements, open decisions, and phased delivery plan. The original project brief is preserved in `forge bot docs.rtf`.

Generated designs and code require engineering review. A browser visualization or physics simulation does not establish that a physical robot is safe or ready to manufacture.
